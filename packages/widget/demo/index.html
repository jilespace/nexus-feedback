Widget Demo

可嵌入的反馈入口

这是一个模拟宿主产品的页面，右下角通过 IIFE 脚本嵌入了 Nexus Feedback Widget。 宿主页与 Widget 使用不同的字体与按钮样式，可用来验证样式隔离、主题变量与同源 API 代理。

一键嵌入

加载单个 IIFE 文件，调用 NexusFeedbackWidget.mount() 即可。

样式隔离

Widget 使用 Shadow DOM 渲染，宿主页面的全局样式不会影响它。

同源代理

本 demo 服务器把 /api/* 代理到本地 API，避免 CORS 配置。

嵌入代码

构建 packages/widget 后，dist 产物由本 demo 服务器直接提供。

<script src="/dist/nexus-feedback-widget.iife.js"></script>
<script>
  NexusFeedbackWidget.mount(container, {
    apiKey: 'nf_demo_project_key_789',
    apiUrl: '/api/v1',
    position: 'bottom-right',
    theme: { primaryColor: '#3D5AFE', radius: 16, density: 'compact' },
    locale: 'zh',
  });
</script>
Widget 构建产物不存在（packages/widget/dist/nexus-feedback-widget.iife.js）。 请先运行 pnpm --filter @nexus-feedback/widget build，然后刷新本页。
